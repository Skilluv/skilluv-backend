# Le domaine Design sur Skilluv

*Index public. Chaque document ci-dessous est destiné à être publié sur
`skill-uv.com/design`.*

---

## En une phrase

Un designer arrive avec un métier — n'importe lequel des vingt-six —, prend un
brief réel, le rend, reçoit une critique argumentée, le reprend, et repart avec
une preuve qu'un inconnu peut vérifier.

## Ce qui distingue ce domaine des autres

Le code a une CI verte. La cybersécurité a une preuve d'exploitation. Le design
n'a ni l'une ni l'autre : **tout y est jugé par des humains**, et c'est ce qui
a dicté toute la construction.

Quatre conséquences, visibles dans les documents qui suivent :

1. **La boucle de critique est le produit.** Jusqu'à cinq tours, chacun avec un
   motif obligatoire, et une trace publique. Un travail validé après trois
   tours vaut plus qu'un validé du premier coup.
2. **La grille est publiée avant.** Personne n'est jugé sur un critère qu'on ne
   lui a pas montré. Treize grilles de famille, plus une grille commune où
   l'accessibilité est demandée à tout le monde.
3. **Le droit de relire est accordé par famille.** Un typographe ne juge pas un
   brief de motion, et le code le refuse.
4. **Les concours dotés séquestrent l'argent avant d'ouvrir.** C'est une
   contrainte de base de données, pas une bonne intention — c'est la seule
   chose qui sépare un concours du travail spéculatif.

## Les vingt-six métiers, par famille

| Famille | Métiers |
| --- | --- |
| `product` | produit, design system, conversationnel |
| `web` | web, éditorial web |
| `mobile` | mobile |
| `motion` | motion d'interface, motion 2D, motion 3D, vidéo |
| `brand` | identité, typographie, nommage et verbal |
| `illustration` | illustration, iconographie, personnage |
| `dataviz` | visualisation de données |
| `ux-writing` | écriture d'interface |
| `marketing` | design marketing |
| `game` | interface de jeu, environnement de jeu |
| `3d-viz` | architecture et intérieur |
| `immersive` | AR/VR spatial, design sonore |
| `service` | design de service, design ops |

**Ouverture progressive.** La communication publique commence par les huit
métiers les plus proches du reste de la plateforme ; les dix-huit autres sont
ouverts en base et attendent des relecteurs. C'est écrit plutôt que caché :
une promesse d'écosystème vide est pire qu'un domaine annoncé comme jeune.

## Ce que la plateforme ne fera pas

- **Importer votre portfolio.** Un compte Behance ou Dribbble se déclare et
  n'entre dans aucun score. Un score qu'on peut faire monter en important une
  page cesse de vouloir dire « prouvé ici ».
- **Noter automatiquement une proposition.** Des vérifications partielles
  existent — contraste, poids, formats — et ne décident jamais d'un verdict.
- **Prendre une commission sur une dotation de concours.** Les entreprises
  payent, les talents non ; une commission prélevée sur un prix est de l'argent
  pris au lauréat.
- **Céder vos droits.** La plateforme reçoit une licence d'affichage, rien de
  plus.
