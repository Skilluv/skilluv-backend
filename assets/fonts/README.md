# Fonts

These are the typefaces of the Skilluv design system, embedded so the backend
can rasterise text server-side — currently the OpenGraph card served by
`GET /api/verify/{hash}/og.png` (SKI-292).

| File | Family | Role in the design system |
| --- | --- | --- |
| `BricolageGrotesque-Variable.ttf` | Bricolage Grotesque | `--font-sans`, the body and heading face |
| `JetBrainsMono-Variable.ttf` | JetBrains Mono | `--font-mono`, used here for the attestation hash |

## Why they live here

The card is generated by the server, so the glyphs have to be available at
runtime. Relying on system fonts would mean the published container renders
different — or empty — text depending on which base image it was built from,
and would fail silently: a card with no text still returns 200 and still gets
cached by the social platforms that fetch it.

Embedding them makes the output identical everywhere and removes a runtime
dependency on the host.

## Where they come from

Copied from the frontend's `@fontsource-variable` packages, so both surfaces
render the same brand:

- `@fontsource-variable/bricolage-grotesque`
- `@fontsource-variable/jetbrains-mono`

`@fontsource` ships WOFF2 only, which `fontdb` cannot decode. They were
converted once, offline:

```
python -c "from fontTools.ttLib.woff2 import decompress; \
           decompress('in.woff2', 'out.ttf')"
```

Only the `latin` subset is kept — the card renders usernames, a repository
name and a date. Should the card ever need another script, take the matching
subset from the same package rather than a different source.

## Licence

Both are under the SIL Open Font License 1.1, which permits redistribution
including in a commercial product, provided the licence travels with the
font. The full texts are alongside, in `*-LICENSE.txt`. They must not be
removed, and the fonts must not be sold on their own.

Fraunces (`--font-display`) is deliberately absent: the card does not use it,
and an unused 100 KB in the binary is 100 KB of nothing.
